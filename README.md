# oliral.github.io

Persoonlijke website van **oliral**, gepubliceerd via GitHub Pages.

🌐 **Website:** https://oliral.github.io

## Over deze website

Deze repository bevat de bestanden voor de website. De inhoud en vormgeving worden beheerd via GitHub en online gepubliceerd met GitHub Pages.

## Aanpassen

Wijzig de websitebestanden in deze repository en commit de wijzigingen naar de branch die voor GitHub Pages is ingesteld. Na publicatie zijn de updates op de website te zien.

## Lokaal bekijken

Open het hoofdbestand van de website, bijvoorbeeld `index.html`, in een browser. Als de site functies gebruikt die een lokale webserver vereisen, start die dan vanuit de projectmap.

## Publicatie

De publicatie-instellingen zijn te vinden in de repository onder **Settings → Pages**. Daar kun je controleren welke branch en map als bron voor GitHub Pages zijn ingesteld.
